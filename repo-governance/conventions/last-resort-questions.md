# Last-Resort Questions

Exhaust the repository before asking. A question whose answer is written down costs the reader more than it costs the asker.

## Before Asking

- Read the governing document. Root [`AGENTS.md`](../../AGENTS.md) is an index into every rule this repository has.
- Read the specification. `specs/behaviours/` is canonical for what the binary does, and `specs/architecture.md` for how it is built.
- Run the thing. A gate, a `--help`, or a one-line probe answers most questions about behaviour faster than a message does, and answers them with evidence.
- Check whether the ambiguity changes anything. Where two readings lead to the same work, pick one, say which, and continue.

## When to Ask

Ask when proceeding under any reading would be unsafe, would destroy something, or would make the work useless if the guess were wrong. Ask once, with the options and a recommendation, rather than serially.

Ask at the right moment: do everything the answer does not block first, so the question arrives with the rest of the work already done.

## How to Ask

State what was tried, what the repository says, and what the two possible readings would each produce. A question that arrives with that context is a decision the reader can make in one pass; a question without it is a request to redo the investigation.
