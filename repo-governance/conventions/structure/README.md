# Structure Conventions

Conventions adopted from the shared catalog that fix where a kind of artifact lives. They keep the catalog's path, so
the adopted agents and standards that link them resolve unchanged.

## Directory Map

- [Stack packs](stack-packs.md) — where each stack's standard and skill live, and how an agent finds a project's packs.
- [Stack packs modules](stack-packs/README.md) — the ordered modules of that convention: the repository adapter and the
  inventory extension.
