# Principles

Durable constraints that hold across every convention, standard, and workflow in this repository. They change rarely, and changing one is expected to change documents below it.

Principles sit under the [vision](../vision/README.md) and above the [conventions](../conventions/README.md).

## Directory Map

- [Governance continuity](governance-continuity.md) — rules survive context loss, compaction, and handover.
- [Minimal sufficiency](minimal-sufficiency.md) — understand, reuse, minimize, verify.
- [Progressive disclosure](progressive-disclosure.md) — the index is short so the rules get read.
- [Repository independence](repository-independence.md) — this tool holds no defaults about the work it guards.
