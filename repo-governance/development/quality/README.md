# Quality

Software-development standards adopted from the shared catalog. They keep the catalog's paths, so the adopted agents,
skills, and stack standards that link them resolve unchanged. Where a concept already had a local owner in
[development](../README.md), the local owner was kept; the [repository adapter](stacks/repository-adapter.md) lists
both.

## Directory Map

- [Checks](checks/README.md) — the threshold and waiver rule every lint gate follows.
- [Code](code/README.md) — language-neutral rules for type safety at boundaries and for shell scripts.
- [Stacks](stacks/README.md) — the adopted stack standards and the repository adapter.
- [Testing](testing/README.md) — what a coverage number may measure.
